# Frontend — навигатор «Колибри»

Angular 22 + SSR. Ходит в бэкенд по `/api` (в dev через `proxy.conf.json` на
`127.0.0.1:3000`, на сервере — напрямую, адрес берётся из `API_BASE_URL`).

```bash
npm ci
npm start                       # http://localhost:4200, прокси /api → :3000
npm run build && PORT=4000 npm run serve:ssr:twc
npm test                        # vitest: 31 тест (сервисы, авторизация, пиктограммы, страницы, формы)
```

## Страницы

| Путь | Что |
|---|---|
| `/` | Приветствие (`welcome_text` из настроек) и выбор аудитории |
| `/:audience` | Корневые темы аудитории (`parents`, `specialists`, `self`) |
| `/:audience/:id` | Узел сценария: меню, ответ, запись, донат, волонтёрство, ссылка |
| `/consult` | Запись на консультацию: форма → проверка данных → подтверждение |
| `/help` | Контакт координатора и инструкция |
| `/admin/login` | Вход для сотрудников (почта и пароль) |
| `/admin/requests` | Заявки: фильтр по статусу, смена статуса, выгрузка CSV |
| `/admin/slots` | Свободные окна календаря: добавить, удалить |
| `/admin/scenarios` | Конструктор сценариев: дерево кнопок по аудиториям, форма узла |
| `/admin/settings` | Тексты, ссылки, контакт координатора, открытие записи |
| `/admin/users` | Сотрудники: добавить, отключить, сменить свой пароль |

Админка рендерится только в браузере (`RenderMode.Client`), токен лежит в
localStorage, интерцептор добавляет `Authorization: Bearer` к `/api/admin/*`
и разлогинивает при 401. Страницы под `/admin` закрыты guard-ом.

## Структура

```
src/app/
  core/api.ts      # типы и запросы к бэку (httpResource), AUDIENCES
  core/prefs.ts    # размер текста и звук, localStorage
  core/speech.ts   # озвучка по нажатию (Web Speech API)
  core/nav.ts      # родитель текущего узла для кнопки «Назад»
  core/auth.ts     # сессия сотрудника, интерцептор, guard
  core/admin-api.ts# запросы админки
  ui/picto.ts      # плоские пиктограммы без лиц, подбор по типу/подписи
  ui/listen.ts     # кнопка «Прослушать»
  pages/           # home, topics, node, consult, help
  pages/admin/     # login, layout, requests, slots, scenarios, settings, users
  app.*            # шапка с настройками, нижняя навигация
styles.scss        # палитра из «Правил дизайна TWC», кнопки, формы
```

## Как реализованы правила дизайна

- Один вопрос на экран, пошаговая форма с проверкой данных перед отправкой.
- Пиктограмма всегда с подписью. Если у узла есть `image_url`, показывается он.
- Нет анимаций, автопереходов и автозвука: озвучка только по кнопке, с остановкой.
- Постоянная нижняя навигация «Назад», «К темам», «Помощь» на всех страницах кроме главной.
- Размер текста и звук сохраняются между входами.
- Ошибка объясняет, что делать дальше, и не теряет введённые данные.
- Кнопки не ниже 56 px, видимый фокус, контраст по палитре.
